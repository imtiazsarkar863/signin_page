# Sign In / Sign Up Pages

A static sign-in and sign-up interface built with HTML and CSS.

## Preview

Open `signin.html` in a web browser, then use the sign-up link to open `signup.html`. No build tools or package installation are required.

## Project Files

- `signin.html` - Sign-in page
- `signup.html` - Sign-up page
- `front.png` - Sign-in background image
- `back 2.png` - Sign-up background image
- `g.svg` and `m.svg` - Google and Microsoft logo assets

## Note

These pages provide the front-end interface only. User authentication and account registration require a backend and configured authentication routes.
